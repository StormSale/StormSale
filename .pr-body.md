## Summary

This PR implements comprehensive test coverage for enterprise B2B features across four related test suites addressing PRs #438, #439, #440, and #428.

## Tests Added

### #438: Enterprise Billing Statement and Tax Invoice PDF Export
- **26 tests** covering:
  - Dynamic enterprise tax data insertion (tax ID, address, legal entity name)
  - Mathematical accuracy of VAT calculations and totals
  - PDF generation and download functionality
  - Print stylesheet formatting for paper archiving

### #439: Enterprise Webhook Endpoint Configuration and Ping Tests
- **41 tests** covering:
  - HTTPS validation for production webhook URLs
  - Webhook ping testing with response latency measurement
  - Secret regeneration with confirmation modals
  - JSON payload preview rendering with syntax highlighting

### #440: Enterprise Audit Log Filter, Search and Export
- **38 tests** covering:
  - Audit log filtering by actor, date range, and action type
  - Debounced search across metadata payloads
  - Export to signed JSON and CSV formats
  - Filter state persistence

### #428: Account Merge and Balance Synchronization
- **29 tests** covering:
  - Account merge detection and UI reactions
  - Trustline balance reloads (USDC, EURC, STORM) without page refresh
  - Balance accuracy and consistency verification
  - Full page refresh prevention via streaming updates
