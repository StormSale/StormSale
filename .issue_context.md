### Context & Motivation
Before broadcasting contract invocations, Soroban requires transaction simulation to estimate resource fees and compute units. This test suite verifies how the frontend handles simulation errors (e.g. HostError, insufficient balance, SlippageExceeded).

### Acceptance Criteria
- [ ] Test simulation response parser decoding Soroban error codes into human-readable messages.
- [ ] Verify pre-flight balance check prevents submitting transactions if XLM fee reserve is insufficient.
- [ ] Test UI warning display when transaction resource fees exceed user's slippage tolerance.
- [ ] Ensure simulation timeout (10s) gracefully aborts with retry prompt.
