### Context & Motivation
The frontend integrates Stellar Wallet Kit supporting Freighter, xBull, Albedo, Hana, and WalletConnect. We need a comprehensive unit test suite covering connection lifecycles, user-initiated disconnections, rejection handlers, and unexpected wallet disconnect events.

### Acceptance Criteria
- [ ] Mock all supported wallet adapters using `@stellar/freighter-api` and `@creit.tech/stellar-wallets-kit` mocks.
- [ ] Verify state transitions: `idle` -> `connecting` -> `connected` -> `disconnecting` -> `disconnected`.
- [ ] Test graceful handling when user denies connection request in wallet popup.
- [ ] Test auto-reconnection behavior on page reload when a valid session token exists in `localStorage`.
- [ ] Test account switching event emission and synchronized UI state updates.
