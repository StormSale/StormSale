## Description:
### Target Branch: `dev`

### Context & Motivation
Production dApps cannot rely on a single Soroban RPC node. The client maintains an RPC fallback pool. We require a test suite verifying seamless endpoint failover when the primary RPC returns 429, 502, 503, or times out.

### Acceptance Criteria
- [ ] Test RPC request failure interceptor switching from primary to secondary/tertiary endpoints.
- [ ] Verify exponential backoff and jitter configuration during network congestion.
- [ ] Verify user alert banner triggers only after all backup RPC endpoints fail.
- [ ] Test circuit breaker pattern preventing repeated calls to dead RPC nodes.
- [ ] Test health-check polling restoring primary RPC once connectivity recovers.

### Verification Command
`npm test src/tests/soroban-rpc-failover.test.ts`
