# Security Policy

## Supported Versions

We actively maintain and provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

The StormSale security team takes all vulnerabilities seriously. If you discover a security flaw or vulnerability affecting our smart contracts, frontend, or backend microservices, please report it responsibly.

### How to Report

- **Email**: `security@stormsale.io` (or directly to `abujulaybeeb08@gmail.com`)
- **PGP Key / Encrypted Message**: Available upon request.
- **Do NOT open a public GitHub issue** for undisclosed security vulnerabilities.

### What to Include in Your Report

1. Description of the vulnerability and its potential impact.
2. Step-by-step instructions to reproduce the issue (PoC code or transaction traces are highly encouraged).
3. Any suggested remediations or patches.

### Our Commitment

- **Acknowledgment**: Within 48 hours of initial report.
- **Assessment & Status Update**: Within 5 business days.
- **Responsible Disclosure**: We coordinate patch releases and publicly credit security researchers upon resolution.
